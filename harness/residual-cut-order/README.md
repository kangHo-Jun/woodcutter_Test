## CASE11은 원본 설정 확정 전

사진에서 읽은 원판1820×910, A685×840/B300×840/C173×840 각1개,
D195×650 4개를 넣었다. 톱날4.2, 자동, 회전ON, 결OFF, 전단OFF, 두께18은
임시 가정이다. 마지막 조각이 기존 D650×195인지 별도654×195인지도 확인 중이다.

사용자 요구 절단 순서: A/B/C 세로 분리 → 오른쪽 통높이 잔재를 높이650에서
가로 분리 → 위에서 세로D3개 → 아래에서 가로D1개.

4.2mm 조건에서는 ABC 배치를 유지할 때 오른쪽 실폭이649.4mm로 D650보다0.6mm
작다. 따라서 현 테스트의 정확한 배치를 이 설정으로 GREEN으로 만드는 것은
허용되지 않는다. 사진 표시654를 실제 잔재로 간주하거나 톱날/허용오차를
느슨하게 해서 통과시키지 않는다. 먼저 실제 설정을 확인하고 fixture에 반영한다.
기존10개의 입력/기준값은 바꾸지 않는다.
