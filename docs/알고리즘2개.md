# 알고리즘 비교

## 알고리즘 A: 현재 로직 개선
- 기본 방향: 현재 스트립 기반 로직 유지
- 목표: D(긴 부품)를 패턴1에 배치하는 후처리 추가
- 핵심: 가로 절단 후 하단 전폭 공간을 freeRect로 정확히 등록
- 장점: 다양한 부품 조합에 유연, 공간 효율 높음
- 단점: 복잡한 후처리 필요, 긴 부품 배치 불안정

## 알고리즘B: 길이 방향 절단 우선
- 길이(2440mm) 방향으로 관통 절단 우선
- 도면 기준: 가로(Y축) 절단
- 상단 스트립에 큰 부품 배치
- 하단 짜투리를 가로 띠로 집중 -> 최소화
- 구현: packHorizontalPrimary() 기반
