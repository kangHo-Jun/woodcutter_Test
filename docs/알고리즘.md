# 재단 최적화 알고리즘 가이드

## 기본 용어 정의
- **원장**: 작업 대상 판재 (기본 1220×2440mm)
- **폭**: 짧은 방향 = 1220mm (도면 세로)
- **길이**: 긴 방향 = 2440mm (도면 가로)
- **길이절단**: 길이(2440) 전체를 관통하는 가로선 절단
- **폭절단**: 폭(1220) 전체를 관통하는 세로선 절단
- **짜투리**: 재단 후 남는 빈 공간
- **kerf**: 톱날 두께 (기본 4.2mm)

---

## 원칙 (절대 변경 불가)
1. 모든 절단은 **관통 절단** (중간에 멈추지 않음)
2. 절단된 조각은 **새 원장**으로 취급
3. 도면은 항상 **가로(길이2440) × 세로(폭1220)** 방향으로 표시

---

## 알고리즘A: 기존 스트립 방식
**파일**: `js/packer.js` → `AdaptiveGuillotineBin` 클래스

### 동작 방식
원장에서 스트립(가로 띠) 생성
→ 스트립 내 부품 배치
→ 우측 잔여공간 재귀 처리
→ 하단 잔여공간 다음 스트립

### 장점
- 다양한 부품 크기 조합에 유연
- 공간 효율 높음

### 단점
- 긴 부품(D=1270mm) 배치 어려움
- 짜투리가 여러 조각으로 분산

---

## 알고리즘B: 길이절단 우선 방식 ⭐ 현재 적용
**파일**: `js/packer.js` → `guillotineCutB()` 함수

### 핵심 원칙
> 하부 짜투리 최소화 = 판재 수량 최소화 = 컷수 최소화

### 동작 방식 (예시)
원장 (폭1220 × 길이2440)
1단계: 가장 큰 부품(A=750폭) 기준으로 길이절단
→ 상단 (폭750 × 길이2440)
→ 하단 짜투리 (폭470 × 길이2440)
2단계: 상단 원장에서 A 배치 후 우측 재귀
→ A (길이820 × 폭750) 배치
→ 우측 (폭750 × 길이1620) 새 원장
3단계: 우측 원장에서 B 기준 길이절단
→ 상단 (폭450 × 길이1620): B, C, E 배치
→ 하단 (폭300 × 길이1620): D 배치
결과: 1장으로 모든 부품 배치!

### 선택 기준
알고리즘A 판재수 vs 알고리즘B 판재수
→ 적은 쪽 선택
→ 같으면 B 선택 (작업자 편의)

## 핵심 코드 위치

### packer.js
guillotineCutB(rect, items)     ← 알고리즘B 메인 함수
AdaptiveGuillotineBinB.pack()   ← 알고리즘B 실행
packAdaptiveAuto()              ← A,B 비교 후 선택

### main-unified.js
handleCalculate()               ← 계산 시작
→ packerW = Math.max(w,h)    ← 항상 긴 쪽을 width로
→ packerH = Math.min(w,h)    ← 항상 짧은 쪽을 height로

### main-unified.js (도면 렌더링)
drawBinToCanvas()
→ isPortraitBoard = false     ← 항상 가로 방향 도면
→ renderBoardWidth = Math.max ← 길이(2440)를 가로로
→ renderBoardHeight = Math.min← 폭(1220)을 세로로

---

## 폭/길이 설정 주의사항

### 입력값
boardWidth  = 사용자 입력 첫번째 값
boardHeight = 사용자 입력 두번째 값

### 내부 처리
packerW = Math.max(boardWidth, boardHeight) → 항상 2440
packerH = Math.min(boardWidth, boardHeight) → 항상 1220

### 이유
> 사용자가 1220을 먼저 입력하든 2440을 먼저 입력하든
> 내부에서는 항상 2440×1220 기준으로 계산

## 로직 수정 가이드

### guillotineCutB() 수정 시 주의사항

1. **heightCandidates 수집**
   - `item.height`만 등록 (회전 후보 제외)
   - 이유: 회전하면 bestHeight가 커져서 하단 공간 낭비

2. **bestHeight 선택**
   - waste(하부 남은 폭) 최소 기준
   - waste = rect.height - h

3. **재귀 구조**
   - 우측 재귀: 같은 스트립 높이 유지
   - 하단 재귀: 새 원장으로 처음부터 계산

4. **부품 배치 순서**
   - 면적 큰 순서로 정렬
   - 한 스트립에 여러 부품 배치 가능
