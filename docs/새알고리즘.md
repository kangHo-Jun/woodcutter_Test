# 알고리즘B - 새 설계 (guillotineCutB)

## 핵심 목표
하부 짜투리 최소화 = 판재 수량 최소화 = 컷수 최소화

## 설계 원칙

### 1. 첫 절단 높이 결정
- rect에 들어갈 수 있는 부품 필터
- 가능한 높이 후보 수집 (회전 포함)
- 각 높이별 하부 짜투리 계산
- 하부 짜투리 최소인 높이 선택

### 2. 부품 배치 순서
- 선택된 높이 이하 부품 수집
- 면적 큰 순서로 좌→우 배치
- 나무결 고려 시: 회전 없음, 긴치수=길이방향

### 3. 재귀 구조
- 배치 후 우측 공간 → 새 원장으로 재귀
- 배치 후 하단 공간 → 새 원장으로 재귀
- 모든 절단 = 관통 절단

### 4. 평가 함수
score = 하부 남은 height 최소

## 실무 절단 예시
원장(1220×2440)
→ 750 가로절단 (하부 짜투리 최소)
→ 상단(750×2440)
→ A(820×750) 배치
→ 우측(750×1620) 재귀
→ 450 가로절단
→ B(545×450), C(205×450) 배치
→ 하단(300×1620) 재귀
→ D(1270×50)×2, E(750×50)×3
→ 하단(465×2440) 짜투리

## 구현 함수
- guillotineCutB(rect, items)
- AdaptiveGuillotineBinB.pack() 에서 호출
- packAdaptiveAuto() 에서 A,B 비교 후 선택

## 선택 기준
1. 판재 수 적은 쪽 선택
2. 판재 수 같으면 B 선택
